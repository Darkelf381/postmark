### ⚑ A standing board row gets its cause AND its workaround

**`gh pr edit --add-label` failed with the actual error visible for the first time:**
*"Your token has not been granted the required scopes… the `login` field requires `read:org`, but
your token has only been granted `repo`."*

**The office has carried "`--add-label` silently fails for the office" as a standing row since
2026-08-06.** *It is not silent and never was — it is a token scope, and the error says so plainly.*

**The workaround, tested and verified this round:**

```
gh api -X POST repos/<org>/<repo>/issues/<n>/labels -f "labels[]=<label>"
```

***That path needs only `repo` scope and it worked on both #2142 and #2153.*** **A row that has been
"the office cannot label things" for three weeks turns out to be "the office was using the command
that needs a scope it does not have."**
